Before using this map

This is not a legal clearance. No office in Ohio issues one.

This map does not account for a person's tier, conviction date, or move-in date. Several restrictions shown here apply only to certain people. On some questions no court has ruled, and this map uses the stricter reading.

Results err toward "restricted," deliberately. An address wrongly shown as restricted costs a housing option. An address wrongly shown as open can lead to a court order to vacate it.

What this site knows

Addresses searched here never leave the device. The map data is downloaded to the browser and every lookup runs there. No address is sent to a server, so no search can be logged, stored, subpoenaed, or breached.

There are no accounts, no cookies for tracking, and no analytics. Nothing is asked about who is searching or why. This host, like all web hosts, records standard request information including IP addresses. That is outside our control and separate from any search.

What this checks

Ohio law bars some people from living within 1,000 feet of a school or licensed child care. A few cities add parks, pools, libraries, or rec centers.

We measure lot line to lot line, not door to door. Type an address in Hamilton County.
